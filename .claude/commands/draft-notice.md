---
description: "Draft a distribution notice, a capital call reminder or a letter to a holder. Drafts only."
---

Read `CLAUDE.md` first. Read the records first (`holder`, `distribution`, `calls`). Then one of: `npm run registry -- draft-distribution-notice <distribution>`, `npm run registry -- draft-call-reminder <call>`, `npm run registry -- draft-holder-letter "<name>" --about="<topic>"`. Each writes to `drafts/`. Edit the draft for tone; keep every figure from the CLI. Never send: a person sends.
