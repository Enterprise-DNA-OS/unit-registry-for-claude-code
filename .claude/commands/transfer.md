---
description: "Register an off-market transfer of units from one holder to another."
---

Read `CLAUDE.md` first. Check both holders with `npm run registry -- holder`. The receiving holder must be verified first. Run `npm run registry -- transfer --fund=<fund> --from="<seller>" --to="<buyer>" --units=<n> --on=YYYY-MM-DD`. Keep the signed transfer form with your records; note where it is with `log`.
