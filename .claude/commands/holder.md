description: "Everything about one holder: details, holdings, transactions, distributions and notes, before you write to them or change anything."
---

Read `CLAUDE.md` first. Run `npm run registry -- holder "<name or SRN>"`. Partial names work; if the CLI lists several candidates, show them and ask which one. Summarise in five lines: what they hold and its value, their last movement, distributions received and withheld, identity and tax status, the latest note. Never quote a TFN or bank number: this system records only whether one was given.
