---
description: "Render the paperwork in your brand: holding statements, distribution statements, periodic and exit statements, capital call notices, the register extract."
---

Read `CLAUDE.md` first. Run `npm run docs` for everything or `npm run docs -- <document>` for one of: holding-statement, distribution-statement, periodic-statement, capital-call-notice, register-extract. Files land in `docs-out/`; open in a browser and print to PDF. Business name, logo and colours come from `brand.json`.
