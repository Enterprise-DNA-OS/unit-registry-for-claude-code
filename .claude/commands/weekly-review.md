Read `CLAUDE.md` first. Run `npm run registry -- attention --json`, `npm run registry -- compliance --json` and `npm run registry -- fund-review --json`. Write `drafts/weekly-review.md`: 1) decisions needed this week (approvals, settlements), 2) compliance items by due date with the rule, 3) money owed to the fund (unpaid calls) and by the fund (approved distributions not yet paid), 4) per-fund one line. Cite references. Never add amounts across currencies.
